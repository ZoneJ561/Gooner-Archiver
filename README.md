Gooner Archiver downloads and organizes publicly accessible pictures, videos, and audio from supported creator and video pages. It includes a persistent queue, resumable downloads, searchable archive history, external download-manager URL exports, and automatic application updates.

## Features

### Media Downloads

- Download individual public video pages, creator posts, and supported creator profiles.
- Save pictures, videos, and audio into separate creator folders.
- View per-file progress, transfer speed, size, and ETA.
- Pause, resume, retry, cancel, remove, and reorder queued files.
- Preserve partial downloads for later resumption.

### Archive And Organization

- Keep a persistent download queue between app sessions.
- Index completed downloads in a local SQLite archive.
- Search the archive by filename, creator, site, type, source URL, or local path.
- Detect moved or missing archived files.
- Export plain-text URL lists for IDM and JDownloader.

### Updates

- Check for Gooner Archiver updates from inside the Windows app.
- Download verified app updates automatically in the background.
- Verify downloaded installers with SHA-256 before installation.
- Display the complete release changelog before installing an update.
- Keep yt-dlp current automatically in source installations.

## Getting Started

1. Download and run the latest installer from the [Releases page](https://github.com/ZoneJ561/Gooner-Archiver/releases/latest).
2. Choose a download folder and the media types you want to save.
3. Paste a supported creator, post, or individual video URL.
4. Confirm that you are legally allowed to save the content.
5. Choose **Download** and manage files from the Queue and Archive tabs.
